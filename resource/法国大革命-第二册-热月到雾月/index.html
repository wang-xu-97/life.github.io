第二册：从热月到雾月（1794.5–1804）
#

衔接说明：第一册止于 1794 年 5 月 20 日（图罗被召回）。距离热月政变还有 68 天。
本册目标：补结构、补后热月、补"为什么"。

〇、先诊断：你的笔记强在哪、缺在哪
#

维度你的笔记需要补的
事件密度极强（日级、含兵力与番号）无
原始文献强（Archives parlementaires 直接引用）读法：文本在跟谁论辩
军事强（战役、将领、兵力）战争如何反过来塑造政治
制度弱（法令多，机制少）委员会怎么运作、法令怎么执行
财政几乎空白指券、限价、破产——革命的发动机
空间以巴黎为中心巴黎 / 外省 / 边境"三个法国"
后热月空白本册主体

一、三个补丁（读第二册之前必须装上）
#

补丁 1：三个法国
#

大革命不是"巴黎的革命"，是三个空间同时运转：

空间主角逻辑代表事件
巴黎无套裤汉、各区、俱乐部、公社面包价格 + 街头暴力十月事件、8.10、9 月屠杀
外省农民、联邦派、保王党、拒誓教士土地、什一税、地方自治大恐慌、旺代、里昂、联邦派叛乱
边境军队、代表在使命、敌军生死存亡 + 战利品瓦尔米、弗勒吕斯、意大利

用法：任何事件先问"发生在哪个法国"。8.10 是巴黎的胜利，却是外省联邦派叛乱的起点——同一件事在两个空间意义相反。

补丁 2：四种时间
#

时间节奏载体
议会时间日/周法令、投票、委员会报告
街头时间小时/天面包价格、谣言、警钟
战场时间周/月战役、补给、征兵
账簿时间月/年指券发行量、债务、税收

用法：1793 年 9 月的恐怖，是"战场时间"（凡尔登陷落）压倒了"议会时间"的结果。四种时间错位，就是"革命失控"的技术定义。

补丁 3：恐怖不是一个人
#

恐怖有四个独立来源，罗伯斯庇尔只是其中之一：

  1. 法令层：嫌疑犯法令（1793.9.17）、牧月法令（1794.6.10）。
  2. 执行层：代表在使命（卡里耶在南特、富歇在里昂、塔利安在波尔多）——地方权力几乎不受约束。
  3. 基层层：各市镇监视委员会、革命军、无套裤汉自发暴力。
  4. 话语层：“阴谋"叙事——把政治分歧解释为叛国。

结论：热月政变能终结恐怖，恰恰因为它先杀掉了"话语层"的持有者；但执行层与基层层是逐步拆除的，用了整整一年。

二、那 68 天：恐怖的最后加速（1794.5.20–7.27）
#

日期事件意义
5.7（花月18）最高主宰崇拜法令罗伯斯庇尔把"美德"制度化，得罪无神论左派
6.8（牧月20）最高主宰节罗伯斯庇尔以"教主"姿态出现，议员反感
6.10（牧月22）牧月法令取消辩护权、扩大"人民公敌"定义、革命法庭简化审判
6.26（梅月8）弗勒吕斯战役法军胜，外部威胁解除——恐怖失去最强理由
6-7 月巴黎处死人数激增约 1300 人，占巴黎恐怖死亡总数近半
7.26（热月8）罗伯斯庇尔在公会演说暗示还有"未清洗的议员”，全场恐慌
7.27（热月9）政变逮捕罗伯斯庇尔；公社营救失败
7.28（热月10）处死 22 人罗伯斯庇尔、圣茹斯特、库东、阿尼奥等

关键机制：弗勒吕斯（6.26）是转折点。外部胜利让"非常状态"失去理由，而牧月法令（6.10）又把恐怖推向顶点——胜利与恐怖同时到达极限，议员们发现：再不行动，下一个就是自己。

三、热月与督政府（1794.7–1795.10）
#

3.1 热月 9 日：一天之内
#

  • 上午：罗伯斯庇尔在国民公会发言，被嘘，“打倒暴君”。
  • 下午：公会通过逮捕令（罗伯斯庇尔、圣茹斯特、库东、勒巴等）。
  • 傍晚：巴黎公社（Fleuriot-Lescot 等）武装营救，把被捕者带到市政厅。
  • 夜间：公会宣布他们"不受法律保护"（hors la loi），国民自卫军倒向公会。
  • 次日：22 人被处死，恐怖机器的核心被移除。

注意：这不是"反动"，是自保。投票逮捕他的人里，有后来的极端雅各宾派，也有未来的保王党。

3.2 热月党人是谁
#

塔利安、弗雷隆、巴拉斯、勒让德尔、富歇、比约-瓦伦、科洛·德布瓦——成分复杂，唯一共识是"不能再杀下去"。他们很快互相清洗：卡里耶（南特溺杀）1794.12.16 被处死，比约与科洛 1795 年被流放。

3.3 拆解恐怖的时间表
#

日期动作
1794.8.1废除牧月法令
1794.11.12关闭雅各宾俱乐部
1794.12.16处死卡里耶
1794.12.24废除全面限价
1795.4.1芽月起义（面包），镇压
1795.5.20牧月起义，镇压
1795.5.31废除革命法庭
1795.6.17最后六名山岳派被处死（“牧月烈士”，其中三人自杀）

3.4 经济：指券之死
#

  • 1790 年发行 4 亿里弗尔，以教会财产担保。
  • 1795 年流通量约 200 亿，1796 年发行总额约 450 亿。
  • 1797.2.4 指券作废，实际价值趋近于零。
  • 后果：工资、租金、债务全部重估；食利者破产，债务人受益；城市工人实际工资崩溃。

这是理解督政府"腐败无能"的关键：它不是不想治理，是没有货币工具。

3.5 白色恐怖（1795 春）
#

  • 南部（马赛、里昂、普罗旺斯）保王党"太阳公司"（Compagnies du Soleil）屠杀雅各宾派。
  • 死亡人数常被低估：估计数千。
  • 1795.6–7 基贝隆（Quiberon）：逃亡贵族在英国支持下登陆，奥什（Hoche）击败，约 700 人被处死。

3.6 1795 年宪法：一个"没有仲裁者"的设计
#

机构人数职能
元老院（Anciens）250审议、批准或否决法案
五百人院（Cinq-Cents）500提出法案
督政府（Directoire）5 人行政，由元老院选出

缺陷：

  1. 行政无权解散议会，议会无权罢免督政——冲突只能靠政变解决。
  2. 每年改选三分之一，反对派可以合法地逐年壮大。
  3. 没有仲裁者，军队成为唯一"宪法外"的力量。

3.7 葡月 13 日（1795.10.5）
#

保王党在巴黎起义，巴拉斯启用拿破仑，用大炮在圣罗克教堂前镇压。死约百人。这是拿破仑第一次进入政治。

四、督政府（1795.11–1799.11）
#

4.1 机构与人事
#

  • 首任五督政：巴拉斯、勒贝尔、拉雷韦利埃-莱波、勒图尔纳、卡尔诺。
  • 1797 果月后：梅兰·德·杜埃、弗朗索瓦·德·讷沙托进入。
  • 1799 牧月后：西哀士、迪科、戈伊埃、穆兰、罗歇-迪科。

4.2 财政
#

  • 1797.9.30 “三分之二破产”：国债的三分之二被变相赖掉，其余以土地债券偿付。
  • 直接税改革（1798–99）：门窗税、土地税、动产税。
  • 结果：国家信用破产，军队靠战利品与占领区供养。

4.3 政变循环
#

日期政变目的
1797.9.4果月 18 日清洗保王党，卡尔诺逃亡
1798.5.11花月 22 日清洗雅各宾派
1799.6.18牧月 30 日清洗督政，西哀士上台

规律：每次选举产生不听话的多数，就用军队"修正"选举。共和国的合法性被自己消耗殆尽。

4.4 宗教与教育
#

  • 1795 年宪法确立政教分离、信仰自由。
  • 1795.10 巴黎中央学校（Écoles centrales）建立。
  • 拒誓教士问题未解，西部与南部持续动荡。

4.5 战争：从防御到征服
#

  • 1794 年后法军约 75 万（全民皆兵）。
  • 1798.9.5 茹尔当法：20–25 岁义务兵役——现代普遍兵役制的起点。
  • “自然边界"论：莱茵河、阿尔卑斯山、比利牛斯山。
  • “姊妹共和国”：巴达维亚（1795）、赫尔维蒂（1798）、罗马（1798）、帕尔泰诺佩（1799）。

4.6 巴贝夫（1760–1797）
#

  • 1796 年"平等派密谋”：主张废除私有制、共同劳动、平等分配。
  • 1796.5.10 被捕；1797.5.27 与达尔泰一起被处死。
  • 意义：第一次把"政治平等"推进到"经济平等"，也是 19 世纪社会主义的先声。

五、波拿巴：从将军到第一执政（1796–1799）
#

5.1 意大利（1796–97）
#

  • 1796.3.2 任意大利军团司令；4 月翻越阿尔卑斯。
  • 1796.5.10 洛迪桥；1797.1.14 里沃利；1797.2.2 曼图亚投降。
  • 关键：以战养战。在意大利征收数千万里弗尔，部分运回巴黎——既养军，又收买督政府。
  • 1797.10.17 坎波福米奥条约：奥地利割让尼德兰与伦巴第，法国得莱茵河左岸。

5.2 埃及（1798–99）
#

  • 1798.5.19 从土伦出发，3.8 万人、约 400 艘船。
  • 1798.7.21 金字塔战役；8.1 尼罗河海战，法国舰队被纳尔逊摧毁。
  • 1799 年叙利亚远征失败（阿克围城）。
  • 1799.8.22 秘密离开埃及；10.9 登陆弗雷瑞斯；10.16 到巴黎。
  • 意义：埃及是"东方政策"的起点，也是拿破仑政治资本的来源——他把一场战略失败包装成传奇。

5.3 雾月 18–19 日（1799.11.9–10）
#

  • 参与者：西哀士、塔列朗、富歇（警务）、吕西安·波拿巴（五百人院议长）、缪拉、勒克莱尔。
  • 资金：银行家与军需商。
  • 过程：元老院以"雅各宾阴谋"为由把议会迁到圣克卢；波拿巴在五百人院被围攻；吕西安救场；军队清场。
  • 结果：三人执政府（波拿巴、西哀士、迪科），波拿巴任第一执政。

为什么成功：不是因为他强，是因为所有人都需要他——共和派要一个能挡住保王党的将军，保王党要一个能恢复秩序的人，银行家要一个能还债的人。

5.4 1799 年宪法（共和八年宪法）
#

机构职能
第一执政行政全权、立法创议、任命官员
参政院（Conseil d’État）起草法律
保民院（Tribunat）讨论，不能投票
立法院（Corps législatif）投票，不能讨论
元老院（Sénat）护宪、解释宪法
  • 普选被"名流名单"（listes de notabilité）过滤：市镇→省→全国三级名单。
  • 西哀士原话（大意）：“信任从下而上，权力从上而下。”
  • 公投：约 301 万赞成，1562 反对。

5.5 执政府改革（1800–1802）
#

领域措施
行政1800.2.17 省督制（préfet），中央集权定型
财政1800.2.18 法兰西银行；税收包征改革
司法1804.3.21 民法典（后称《拿破仑法典》）
宗教1801.7.15 政教协定：教皇承认没收教产，主教由第一执政提名
荣誉1802.5.19 荣誉军团
教育1802 中学（lycée）制度

5.6 从终身执政到帝国
#

  • 1802.8.2 元老院宣布"终身执政"，8.4 公投批准（约 356 万赞成）。
  • 1804.3.21 当甘公爵被处死（波旁王族，涉嫌保王党密谋）——震慑保王党，也激怒欧洲。
  • 1804.5.18 元老院宣布帝国；12.2 巴黎圣母院加冕，拿破仑从教皇手中拿过皇冠自己戴上。

拿破仑自己的定性（1799.12.15 告法国人民书）：

“La Révolution est fixée aux principes qui l’ont commencée : elle est finie.”
革命已固定在它所由开始的原则上：革命结束了。

5.7 海地：普遍主义的破产
#

  • 1791 圣多明各起义；1794.2.4 国民公会废奴。
  • 1802 拿破仑恢复殖民地奴隶制（5.20 法令），派勒克莱尔远征。
  • 1803 法军失败；1804.1.1 海地独立。
  • 意义：法国革命宣告"人权"，却在殖民地倒退。这是"双元革命"叙事里最深的裂缝。

六、三个关键分析
#

分析 A：为什么恐怖会被自己人终结？
#

不是良心发现，是恐惧的重新分配。

  1. 牧月法令取消辩护权，议员意识到"被告席没有安全区"。
  2. 弗勒吕斯（6.26）解除外部威胁，恐怖失去功能理由。
  3. 罗伯斯庇尔 7.26 演说暗示"还有议员该清洗"，把恐惧变成即时威胁。
  4. 救国委员会内部分裂（卡尔诺、比约、科洛与罗伯斯庇尔对立），没有军队支持他。
  5. 巴黎公社营救失败，国民自卫军倒向公会。

结论：恐怖靠"敌人"维持；当敌人被打败、而恐怖仍在运转，恐怖就开始吞噬自己的主人。

分析 B：督政府为什么必然依赖军队？
#

  1. 宪法设计：行政与立法互相无法解散，冲突无仲裁者。
  2. 选举逻辑：每年改选三分之一，反对派可以合法增长。
  3. 财政破产：没有货币与信用，只能用武力征收。
  4. 战争常态：军队职业化，将军获得独立资源与声望。
  5. 结果：每次危机只能"请军队来修宪法"，直到军队发现可以直接接管。

结论：督政府不是"腐败"，是"分权制在没有共识的社会里无法运行"。

分析 C：拿破仑是革命的继承者还是终结者？
#

继承的部分：

  • 财产权、法律面前平等、世俗国家、中央集权、公制、民法典、民族国家。

终结的部分：

  • 共和制、代议制、政治自由、新闻自由、地方自治。

结论：他是革命的执行人，不是继承者。他用独裁把革命的社会成果固定下来，同时把革命的政治形式清空。1815 年后，这些成果随法典与刺刀传遍欧洲——这既是"双元革命"的传播，也是它的悖论。

七、与"双元革命"的接口
#

霍布斯鲍姆的命题：1789–1848 的世界由两场革命塑造——英国的工业革命、法国的政治革命。

法国革命输出的是：

  • 制度：民法典、公制、省制、世俗国家。
  • 观念：民族主权、公民平等、人权。
  • 悖论：人权与奴隶制并存；民族解放与帝国征服并存。

写作提示：如果你要写"双元革命"的文章，法国革命这一半的核心不是"自由"，而是**“普遍性原则如何在具体利益中被扭曲”**。

  5. “三分之二破产"是什么？
  6. 果月、花月、牧月三次政变各清洗了谁？
  7. 巴贝夫的主张与结局？
  8. 雾月政变的三位执政是谁？
  9. 1799 年宪法如何用"名流名单"过滤普选？
  10. 拿破仑何时恢复殖民地奴隶制？海地何时独立？

论述题

  1. 恐怖统治为什么在胜利之后反而加速？
  2. 督政府的失败是"人的失败"还是"制度的失败”？

答案
#

  1. 1794.6.10；取消被告辩护权、扩大"人民公敌"定义并简化审判。
  2. 外部威胁解除，恐怖失去功能理由；同时牧月法令把恐怖推向顶点，议员自危。
  3. 被指控"阴谋反对国民公会与共和国自由"；公会宣布其不受法律保护。
  4. 元老院 250、五百人院 500、督政府 5 人。
  5. 1797.9.30，国债三分之二被变相取消。
  6. 果月清洗保王党；花月清洗雅各宾派；牧月清洗督政、西哀士上台。
  7. 废除私有制、共同劳动、平等分配；1796 被捕，1797.5.27 处死。
  8. 波拿巴、西哀士、迪科。
  9. 普选产生市镇→省→全国三级"名流名单"，政府从名单中选任。
  10. 1802.5.20 恢复奴隶制；1804.1.1 海地独立。
