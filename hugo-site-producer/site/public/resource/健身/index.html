头前伸矫正计划（预期12周）
#

  1. 收下巴：15次，每天3组
    坐直或靠墙站立，目视前方，水平向后平移头部，感觉后颈有被拉长的感觉，下巴微收，像做出一个“双下巴”的动作，保持5秒
    目标：在等车、刷牙时下意识地做“收下巴”动作，减少无意识前伸；用手机时，坚决举到与视线平行。
  2. 靠墙站立+膈肌呼吸：每日早晚各5min
    后脑勺、肩胛骨、臀部、小腿肚、脚后跟尽量贴墙，收紧核心
    一只手放在胸口，一只手放在腹部，鼻息4秒，鼻呼6秒

@260105更新：

  1. YTW伸展：10次，做2-3组，组间连续做，不休息。3组9min，2组6min
  2. 胸小肌门框拉伸：保持20-30秒，换另一侧重复，每侧2-3次。2~3min

核心训练
#

P1 跳绳+静态激活
#

  1. 跳绳20min
  2. 静态激活：盆底激活，静态稳定
    腹式呼吸（5min）+死虫式（12 x 3，60s间隔，7min）+跪姿平板支撑（4组60s间隔，8min），共20min
    1. 腹式呼吸：
      1. 478呼吸，手放腹部，鼻子缓慢吸气，感觉腹部像气球一样鼓起，将手推开，嘴巴缓慢吐气，发出“嘶”声，同时用力收紧腹部，想象肚脐贴向脊柱，并同步轻微上提盆底肌（如同中断小便的感觉）
      2. 关键：确保胸腔和肩膀保持放松，只有腹部在活动。
    2. 死虫式：
      1. 仰卧，手臂伸直指向天花板，膝盖弯曲呈90度（大腿垂直于地面）。
      2. 在保持下背部紧贴地面的前提下，缓慢交替将对侧的手和腿向地面下放，再收回。全程保持呼吸节奏和腹部收紧。
      3. 组数：每组10-12次/侧，完成2-3组。
