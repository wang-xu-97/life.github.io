健康饮食计划
#

  1. 禁止过于油腻

  2. 控制尿酸

    1. 标准：
      1. 尿酸值：
        持续控制在＜360μmol/L时，痛风石可逐渐溶解；如在＜300μmol/L，溶解的速度会更快
      2. 食物嘌呤摄入量：
        痛风患者在非急性发作期的每日嘌呤摄入建议量通常控制在 150mg - 400mg 之间
    2. 食材嘌呤参考：嘌呤专区
    3. 绝对禁止：
      1. 猪牛鸡鸭 肝、肾
      2. 鱼籽、鲢鱼、鲫鱼、小鱼干、贝类（蛤蜊、牡蛎、扇贝）、虾皮
      3. 所有肉汤、火锅汤、海鲜汤
      4. 鸡精、味精
    4. 注意：
      1. 水煮30分钟香菇≈140mg
        同时香菇的汤汁嘌呤含量50~60mg
      2. 鸡胗138mg
      3. 中嘌呤鱼类：鲤鱼、草鱼、鲈鱼
      4. 中嘌呤蔬菜：紫菜、豆芽（绿豆芽）、芦笋、菠菜、银耳、木耳
      5. 面条、馄饨的汤底
        1. 拒绝高嘌呤骨头/肉类浓汤
        2. 干拌
      6. 紫菜蛋花汤：紫菜属于中嘌呤食物，一般不会过量
    5. 核心原则：
      多吃新鲜蔬菜、蛋奶、主食。
      肉类适量，选择中低嘌呤的种类。
      远离动物内脏和部分海鲜。
      坚决不喝任何肉汤、火锅汤、海鲜汤。

  3. @251027更新：晚上禁止吃蒜超过1瓣

  4. @251231：抗炎饮食

    1. 严格控糖，避免血糖波动过大
    2. 补充Omega3脂肪酸

  5. @260107：工作日午餐避免过辣

    1. 可能引起交感兴奋、血管扩张，导致鼻粘膜水肿，加剧鼻炎鼻塞
    2. 补救：1. 冷水洗脸，2. 温牛奶，3. 调整鼻呼吸

  6. 补充营养参考：目标营养

  7. 低盐

    1. 高尿酸血症每日4g（正常5g）食盐，基本等于不能吃明显的咸味
      1000mg~1500mg 钠（2.5~4g食盐）
    2. 需注意口服补液盐3的含盐量约等于1.1g食盐

  8. 减重
    尽量多吃高蛋白、高饱腹感、低热量、低升糖食物，保证营养的同时制造热量缺口，其中最重要的是替换主食和控制份量

    1. 饱腹感替换：
      1. 主食细粮换粗粮谷物
        1. 白/糯米饭、面条、馒头换成杂粮、薯类、豆类
        2. 杂粮拼 > 紫米饭 > 白/糯米饭 > 馒头 ≈ 面条
      2. 优质蛋白质：鸡蛋、鸡胸肉、瘦肉、牛肉干、无糖（无“风味”）酸奶（希腊酸奶）
      3. 蔬菜
      4. 苹果、蓝莓
      5. 每日坚果15g
    2. 尽量避免
      1. 高热
        1. 油条，194 kcal/ 70g（约一根）
      2. 高升糖
        1. 精制主食：馒头、糯米饭、大米饭、面条等（GI 80+）
          升糖速度甚至高过最快的水果：西瓜（GI 72）
          热量密度也非常高

早睡早起生物钟
#

  1. 目标：10点睡，7点前起，保持生物钟惯性
  2. 早起：
    1. Daily
      1. 晨练、冥想、正念 ——30min
      2. 吃药、补剂、洗漱 ——15min
    2. 周度
      1. 打扫、整理、粘毛 ——10min
      2. 梳毛、喂药、倒水/粮 ——10min
  3. 早睡：
    1. 平衡体力和精力
    2. 理解精体力差，提前2小时消耗体力，接纳剩余体力，保证早睡恢复精力
    3. 认知晚睡后果
      1. 不稳定的作息，基础健康隐患（代谢免疫）
      2. 前额叶决策能力下降、事件预见-闭环能力下降、工作记忆情景记忆认知能力下降
      3. 翌日早起日常习惯中断，对自己完成特定任务能力的信念下降
      4. 脱发、心理压力、心脑血管、体重问题不利因素
      5. 发展停滞

正念计划
# 

非评判觉察
  1. 练习
    1. 把干扰变为正念的锚点，只需觉知“听到了”、“感觉到了”、“看到了”
    2. 不评判：只是声音、动作、想法、评判，这些都只是现象
    3. 内源的干扰、外源的干扰
  2. 益处：
    1. 训练单一锚点的持续注意能力
    2. 训练自动模式切换到觉察模式
    3. 训练与不适情绪共处能力
    4. 非目的性存在的生活方式
    5. 信息压力阈值上升
    6. 提高任务切换效率，减少注意力残留
    7. 降低多巴胺基线阈值
    8. 减少反刍思维
    9. 减少冲动行为
    10. 减少未完成焦虑
  3. 训练阶段
    1. 锚定分心，走神拉回注意力练习(2W)
    2. 扩展觉察，同时注意到呼吸、脚底触感、房间里的空调声，以及一种隐隐的烦躁感——所有这些都能共存于意识中。(2W)
    3. 接纳与不反应，想起一个未完成的任务，不是开始焦虑计划，而是允许它存在，同时继续呼吸。（2M）
    4. 融入日常生活，正念成为一种背景底色，而非一项额外任务。（3M+）
