健康饮食计划
#

  1. 禁止过于油腻

  2. 控制尿酸

    1. 标准：
      1. 尿酸值：
        持续控制在＜360μmol/L时，痛风石可逐渐溶解；如在＜300μmol/L，溶解的速度会更快
      2. 食物嘌呤摄入量：
        痛风患者在非急性发作期的每日嘌呤摄入建议量通常控制在 150mg - 400mg 之间
    2. 食材嘌呤参考：嘌呤专区
    3. 绝对禁止：
      1. 猪牛鸡鸭 肝、肾
      2. 鱼籽、鲢鱼、鲫鱼、小鱼干、贝类（蛤蜊、牡蛎、扇贝）、虾皮
      3. 所有肉汤、火锅汤、海鲜汤
      4. 鸡精、味精
    4. 注意：
      1. 水煮30分钟香菇≈140mg
        同时香菇的汤汁嘌呤含量50~60mg
      2. 鸡胗138mg
      3. 中嘌呤鱼类：鲤鱼、草鱼、鲈鱼
      4. 中嘌呤蔬菜：紫菜、豆芽（绿豆芽）、芦笋、菠菜、银耳、木耳
      5. 面条、馄饨的汤底
        1. 拒绝高嘌呤骨头/肉类浓汤
        2. 干拌
      6. 紫菜蛋花汤：紫菜属于中嘌呤食物，一般不会过量
    5. 核心原则：
      多吃新鲜蔬菜、蛋奶、主食。
      肉类适量，选择中低嘌呤的种类。
      远离动物内脏和部分海鲜。
      坚决不喝任何肉汤、火锅汤、海鲜汤。

  3. @251027更新：晚上禁止吃蒜超过1瓣

  4. @251231：抗炎饮食

    1. 严格控糖
    2. 补充Omega3脂肪酸

真实情感图谱计划
#

感受剥离了喧嚣的娱乐外壳后，那些古老而真实的人类情感：

  1. 宁静和安然
    1. 仁爱、无为、心斋
  2. 悲伤与惆怅
    1. 对失去、无常或人生不完美的触感
  3. 敬畏与惊奇
    1. 世界运行的精致法则
  4. 孤独
    1. 深刻的、存在性的体验，作为一个独立个体的完整性。
  5. @251110 苦楚
    1. 由生存带来的苦楚，正是世界的底色和地球生物的真实脉动

哲学思考：

  1. 亚里士多德：追求中道与幸福
    “中道”（Golden Mean）：美德是两种极端情感之间的平衡。例如，勇敢是懦弱与鲁莽之间的中道。
  2. 存在主义：拥抱焦虑，创造意义
    “自由与责任”：孤独、焦虑、虚无感不是病态，而是人类自由面对无限可能和缺乏先天意义的必然反应。
