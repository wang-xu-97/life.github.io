调整
#

  1. 优先执行运动循环类 60min

    1. 休息/冥想/热身10min
    2. 单车/弱侧激活训练30min
    3. 休息/洗澡20min

  2. SF循环类调整为100+30 -> 130min

计划
#

  1. 弱侧激活渐进训练计划 30min，概括

    1. 热身5min
      1. 猫牛式1min
      2. 左侧臀部激活1min
      3. 站立左膝关节环绕1min正30s+逆30s
    2. 训练主体，2动作循环20min：第一周2组/每个动作 -> 第二周3组/每个动作 -> 第三周加弹力带
      1. 臀桥：12~15次/组
      2. 蚌式开合：15~20次/组；侧卧，屈膝大约九十度，肩髋踝三点一线，双脚并拢，膝关节打开，犹如贝壳开合一样。
      3. 狗鸟式（四足跪姿对侧伸展）：12-15次/组
        </> text 
        从四肢着地的姿势开始，双手与肩同宽，双膝与髋同宽。
收紧核心，保持背部平直。
同时伸出右臂向前，左腿向后，保持身体稳定。
保持这个姿势几秒钟，然后慢慢回到起始位置。
换另一侧，伸出左臂和右腿，重复动作。
      4. 第二周开始：保加利亚分腿蹲：8~10单侧×2/组
        </> text 
        选择一个与膝盖高度接近的平板椅，身体背对它
一条腿曲膝，将脚背放置平板椅上，另一条腿支撑体重
支撑腿向前移动，直至后侧推曲膝角度变大至90-120°左右
支撑腿曲膝，缓慢下蹲，直至支撑腿大腿与地面平行
迅速抬升蹲起，回到起始位置，反复以上动作
下蹲过程中躯干保持中立，目视前方
在体重分配上，大约60%的体重施加在前腿，约40%分配在你的后腿
    3. 拉伸5min
      • 左侧臀部拉伸（1分钟）：仰卧，将左脚踝放到右膝上，双手抱住右大腿向胸口拉拢。
      • 左腿后侧拉伸（1分钟）：坐姿，左腿伸直，右腿弯曲，俯身向左脚尖方向。
      • 左侧大腿前侧拉伸（1分钟）：站立，左手扶墙，右手将左脚跟拉向臀部。
      • 腰部放松（1分钟）：婴儿式放松。跪姿，臀部坐向脚后跟，身体前倾，额头贴地，手臂向前延伸。
      • 泡沫轴放松（1分钟）：如果有泡沫轴，可滚动放松左侧大腿前侧、外侧和臀部。

  2. 睡眠安全感计划20min

  3. 周末计划

    1. 总时长
      1. 8~22：30 -> (14.5-3) × 60 -> 690min × 2 -> 1380min
    2. 运动目标：2运动循环/天 -> 60 × 4 -> 240min
      1. 早饭前能量峰值
      2. 晚饭1小时后能量峰值
    3. SF目标：3SF循环/2天 -> 130 × 4 -> 390min
      1. 弓100min+30
      2. 刀100min+30
      3. 炮100min+30
    4. 自由：1380 - 630 -> 750min -> 12.5H
