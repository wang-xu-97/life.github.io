保持
#

  1. 自由时间
    1. 下班到家后休息时间份额2份，避免视频/直播超过1份时间额度
    2. 每日优先1能量提升活动类
    3. 强化宁早勿晚时间观
    4. 每日1颗维生素B族、1颗维生素D3、2颗鱼油、1片非布司他、2片奥洛他定
    5. 每日2次洗鼻+布地奈德喷药，鼻喷雾保持湿润
    6. 气道通畅时记得收下巴，尽量腹式呼吸，不通优先保持开放气道姿势
    7. 随时关注主频状态
    8. 随身带盐水喷雾
  2. 睡前
    1. 吸尘、洗鼻
    2. 睡眠安全感计划
    3. 倒猫粮、水
    4. 休息deadline：11:00，停止娱乐deadline：10:05
    5. 激情参考边界：11:20
    6. 呼吸机加湿加温
  3. 腹式呼吸模式
  4. 每日闭环事件
    1. 15分钟运动量
    2. 睡前洗鼻
    3. 收纳整理转化正念观察练习——碎片归位练习
      1. 启动期30~60min
      2. 稳定期10min

随笔
#

  1. 感到运用非暴力沟通的困难
    1. 感到需要尽量保持对自我感受的觉知且几乎出于下意识就能用恰当的语言描述当下的感受这件事很困难
      1. 感到要做到这一点，几乎需要保持一个随时都在状态的大脑
        1. 感到因为自己的呼吸太浅，鼻炎、堵、气闷，而无法全然关注当下，并且被快乐多巴胺驱使逃离思考。
          1. 感到要使感官空灵需要极好的器官状态
    2. 感到词语贫乏，感到我似乎会用很多词汇，但又似乎要让自己能无论何时都能任意调遣自己的词汇十分困难。
  2. 然而以上的感到，都是想法，而非感受
  3. 我感到气闷、阻滞和些许焦急，因为我希望尽快完成工作，而我很容易不在状态并且工作看起来很多，这一点又让我感到丧失斗志。
    1. 我希望尽快完成全部的书本回顾和游戏体验回顾，继而完成生活经验回顾，然而想要记录全部的细节，我感到需要一个十分漫长的过程。
    2. 我希望我完成回顾之后可以做到经历和记录的动态平衡。
  4. 然而很多工作从记录来看推进十分困难。
    1. 例如补洞后的填色，完成调色让色块看起来和周围一样对于我来说似乎是一件没有信心的事情。
    2. 卖不再有用处的电子产品似乎也是一个困难，需要仔细对每件物品完全整理收拾齐备，评估价钱，逐个上架最终卖出去。这样的产品大概有坏显示器、不再有用的空气净化器、因为没有扇叶框实用性很低的风扇、车载背部按摩器、旧机箱、旧笔记本。
    3. 地板的卫生问题一直没有深度清理，只是表面的打扫拖地。这件事分块来做是简单的，但是全局来看，需要统计全部的位置，不同位置的清理难度不同，重点在于数量不少，需要每个角落仔细检查。
    4. 定期的卫生问题，包括卫生间定期清洁、猫毛的定期从源头到每个角落全面清理、键盘、屏幕、床上卫生、厨房，这些多数只做了有限的次数，没有做到定期。
  5. 呼吸问题、炎症的刺激、堵、胸闷很容易让我不在状态。
    1. 全然理解自己感受的能力。
    2. 进入状态需要时间启动，更重要的是，似乎存在一种天然的难以捉摸的因素。
    3. 出状态很容易，压力很容易让我离开觉察的状态，而每次出状态想再进状态，需要的不止是时间，也需要消耗意志力。意志力的补充则似乎和消遣娱乐有关，然而消遣娱乐补充意志力的效率似乎又太低，指望正常的休息时间就完全充电似乎是一种幻觉，真实的情况更倾向于完全的沉迷于消遣，直到这种消遣告一段落或是感到无聊，这样意志力就补充回来。这样的过程对比消耗意志力的过程，看起来效率很低。
    4. 最近洗鼻子忽视很多次，鼻腔的状态的好转让我放松了护理，在鼻腔护理这件事上我可以做的更好。更积极地保持洗鼻频率，按时按量喷布地奈德。
  6. 考虑到现实的应激压力，现在选择实行的标准是能让工作运行的方式，工程思维，以工程落地为目标运行，这样的方式，必然导致重要性低的一部分被牺牲以保证最重要的工作顺利运行。
    1. 基础健康 是 核心目标，所以情绪，运动，饮食，睡眠，呼吸被放在最高优先级，形成好好吃饭，保持运动，玩游戏维持情绪，按时吃药、保健品，按时睡觉，维持基础卫生的现实。
    2. 知识进步 是 期望一阶段增量目标，读书、学习工作知识、构建个人项目被放在次高优先级，利用上班空闲时间增量进步，且由于期望需求非常大而不能保证足够认知状态和时间，形成多线增量并进，但完成度低的现实。
    3. 自我关系进步 是 期望二阶段增量目标，正念、自我接纳、慈悲、当下、自我同理、自我非暴力沟通能力，因为实际需要时间和场景耐心练习，形成上班空闲时得以练习，下班则没有时间分配练习的现实。
    4. 社会关系进步 是 期望三阶段增量目标，因为完全没有得到分配，经验不足，信心不足，形成社交、新建社会关系和巩固几乎被完全舍弃的现实。
  7. 模式矛盾
    1. 大脑认知状态不稳定，状态转换非常消耗意志力，且通过消遣的方式恢复意志力占用过多空闲时间。
    2. 知识增量并行线过多，完全占用上班可利用的时间。
    3. 对自我关系进步信心不足，预期不确定，实际期望是稳定大脑认知状态，一劳永逸，减少意志力消耗，提高知识增量、健康能量（包括情绪、体态、肌肉效率）效率。
  8. 可以尝试的改变
    1. 控制娱乐消遣的时间，更多对时间的觉察。
      1. 可能导致意志力赤字，造成情绪问题而导致节奏紊乱甚至更严重后果。
    2. 减少增量并行线，逐个完结。
      1. 需要更多耐心。同样要求稳定的大脑认知状态，而当前的大脑，堵、炎症刺激极易失去状态，同样造成意志力赤字问题。
    3. 减少增量并行线，并且降低隐形效率要求，实现低速且清晰的效率要求，逐个完结。
      1. 可能导致效能感不足，且剩余增量线形成未完成事务负担，需要非常长期的清晰化目标。
      2. 可能导致驱动力不足。
    4. 需要背后的需要，终极愿景
      1. 人为了一些画面活着，类似运筹帷幄、四世同堂、温馨小家，大致都是满足感受的需要
      2. 非暴力沟通总结的人的基本需要：
        1. 自主选择(Autonomy)（梦想、目标、价值以及实现梦想、目标、价值的方法）
        2. 完整性(Integrity)（真实、意义）
        3. 庆祝/哀悼（庆祝创造/梦想实现、创造力、自我价值、哀悼失去：亲人离世、梦想破灭等）
        4. 相互依存(Interdependence)（接纳、亲近、体谅、心理安全、欣赏、社群、服务生命、同理、诚实(the empowering honesty that enables us to learn from our limitations.)、确认、支持、理解、爱、尊重、信任、温暖）
        5. 精神交融(Spiritual Communion)（美、启迪、和平、和谐、秩序）
        6. 玩耍（乐趣、欢笑）
        7. 滋养身体(Physical Nurturance)（空气、食物、运动锻炼、休息、住所、水、保护、性表达、触摸）
      3. 可以看出，要满足自己的全部需要，就需要不断地传递感受、使用语言并且为了使用某些语言而做现实的努力（比如为了庆祝，努力的安排好一切细节，为了精神交融和滋养身体，努力维持自我和自我的环境的秩序，为了相互依存，努力做好自己的一部分，尽力帮助别人或者提供他人需要的换取互利帮助，为了实现梦想，努力挣钱、学习）。这要求我们不断的付出努力关注当下的自我和他人，这意味着高功能大脑认知。
      4. 所以静态的模式和对静态模式的静态调整的背后，实际是期望寻找一个无风的港口，永恒的安定。面对挑战，时刻调整，学习语言，承担责任，是唯一能够尽可能满足自我需要的现实可行的道路。
