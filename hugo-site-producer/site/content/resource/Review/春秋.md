    春秋（770 -> 476 BC，由孔子《春秋》（又名春秋经、麟经、麟史）史书定名）
    东周前半期历史阶段，王室衰微，诸侯征伐，齐（桓公-山东淄博）、晋（文公-山西运
    城）、宋（襄公-河南商丘）、秦（穆公-陕西宝鸡）、楚（庄王-湖北荆州-时称郢ying
    都）称春秋五霸（一说齐晋楚吴（阖闾-江苏苏州）越（勾践-浙江绍兴））

## 柏举之战
    506 BC 吴（蔡、唐）、楚

| 细节 | 备注 |

| 吴王阖闾亲征，以伍子胥、孙武为大将，吴王胞弟夫概为先锋，率3万吴军，与蔡、唐形成3国联军，由孙武之策快速穿越大隧（平靖关/黄岘关/广岘关/百雁关/九里关，河南信阳南）、直辕（武阳关/武胜关，河南信阳南）、冥阨（河南信阳东南）三处楚关隘，挺进汉水东，楚左司马沈尹戌和令尹（楚相）子常（囊瓦/芈囊，芈姓，字子常）计划由尹戌率部北上方城（河南方城），迂回吴军侧背，二军夹击，断其归路。尹戌走后，子常听信谗言，贪功冒进，提前擅自出击，吴军后撤，子常追吴军至小别、大别山区，兵疲，被吴军连败三阵。子常于柏举（湖北麻城）重整军队，迎敌吴军。吴军进攻，楚军溃败，子常逃往郑国（河南新郑市），吴军俘虏楚军大半，后沈尹戌由息县（河南息县）救援，被吴军包围，尹戌令部下吴句卑割其首回报楚王。往后吴军一路报捷，扑向郢都，楚昭王带亲信逃向随国（云梦泽->郧国->随国-湖北随州市），吴军攻入郢都，大胜。|

## 范、中行氏之乱
    晋六卿、仇晋国（齐、卫、郑、鲁、宋、鲜虞）

| 细节 | 备注 |
| --- | --- |
| 506 BC 后，晋国国君（晋定公，姬姓，名午）因三军六卿制度（因“曲沃代翼”，晋文公设立于633BC）失权，大权分入智、赵、韩、魏、范、中行，六卿垄断朝政。 |
| 500 BC 赵孟（晋国赵氏宗主的尊称）赵鞅（谥号简子）联合邯郸大夫赵午（赵氏小宗邯郸午）攻打卫国（河南北、河北南、山东西，帝都帝丘-河南濮阳西南），卫国进贡500户人口议和。 |
| 497 BC 赵氏内乱<br>赵鞅要求邯郸午将卫国进贡的人口迁往晋阳（太原），邯郸父老提议攻齐（山东），赵午如是回复，赵鞅大怒，召赵午到晋阳杀害，赵午之子赵稷及家臣涉宾于邯郸叛乱。 | 邯郸父老提议攻齐：“不可。卫是以为邯郸，而置诸晋阳，绝卫之道也。不如侵齐而谋之。”——表面攻齐，实际希望保留人口 |
| 497 BC 范氏、中行氏联盟<br>赵午是中行氏宗主荀寅的外甥，又因荀寅儿子娶了范宗主范吉射的女儿，范氏、中行氏为亲家，故结盟。 | 1. 荀寅：中行文子/中行寅，姓荀，氏中行，名寅，谥号文，子为尊称<br>2. 范吉射：范昭子，范氏，祁姓，名吉射，谥昭<br>3. 六卿权力格局零和博弈 |
| 497 BC 7月，范、中行伐赵，赵氏退守晋阳。冬11月，智（文子）、韩（不信）、魏（曼多）支持赵氏联盟，奉定公命攻打范、中行，没有攻克。 | 1. 智、韩、魏与范、中行矛盾的史料（并无交恶细节史料）：梁婴父嬖于知文子，文子欲以为卿。韩魏韩简子与中行文子相恶，魏襄子亦与范昭子相恶。—— 左传定公十三年<br>2. 智文子：荀砾，荀氏，按封地为智氏，名砾，谥号文，知文子、智砾、知砾 |
| 497 BC 冬11月 范、中行欲伐晋定公，齐流亡大夫高强劝阻，范、中行不听，伐公，失民心，败，范、中行投奔朝歌（河南鹤壁淇县） | 齐高强曰：“三折肱知为良医。唯伐君为不可，民弗与也。我以伐君在此矣。三家未睦，可尽克也。克之，君将谁与？若先伐君，是使睦也。” |
| 496 BC 冬10月 赵鞅围朝歌，范、中行在齐、魏、郑、鲁、宋、鲜虞（中山）等外国势力支持下据城坚守数年。<br>鲁定公、齐景公和卫灵公在“脾、上梁之间”（“牵”地，河南浚jun县）密谋救援范氏、中行氏<br>齐、宋于“洮tao”（山东省菏泽市鄄juan城县西南） | 1. 晋人围朝歌，公（鲁定公）会齐侯，卫侯，于脾上梁之间，谋救范、中行氏...秋，齐侯，宋公，会于洮，范氏故也。—— 左传·定公十四年<br>2. 齐国长期对晋国的霸权心存不满，一直试图挑战其地位，正好利用范、中行氏之乱削弱晋国，在497BC至490BC作为范、中行氏外部援助的主要发起者和领导者。|
| 494 BC 齐、卫救邯郸，围五鹿（河北省大名县）。<br>秋八月，齐卫于乾侯（河北成安县东南）商议救范，鲁、齐、卫、鲜虞联军伐晋，攻下棘蒲（河北赵县）。 | 1. 夏四月，齐侯、卫侯救邯郸，围五鹿...秋八月，齐侯、卫侯会于乾侯，救范氏也，师及齐师、卫孔圉yu（卫大夫，姓孔名圉谥文，卫灵公女婿，孔子赞其：“敏而好学，不耻下问”）、鲜虞人伐晋，取棘蒲。—— 左传·哀公元年<br>2. 齐侯乃与卫侯先会乾侯，然后鲁师及齐师、卫孔圉、鲜虞人同时伐晋，取棘蒲。—— 毛奇龄 春秋毛氏传 |
| 493 BC 齐郑联军送粮给范氏，被赵氏于戚地铁丘（河南濮阳西北）拦截，双方展开“铁之战/铁丘之战”，郑人大败，晋赵氏俘获齐的千车粮食 |  1. 秋八月，齐人输范氏粟，郑子姚、子般送之。士吉射逆之，赵鞅御之，遇于戚...郑师大败，获齐粟千车。—— 左传·哀公二年<br>2. 阳虎献计：“吾车少，以兵车之旆，与罕、驷兵车先陈。罕、驷自后随而从之，彼见吾貌，必有惧心。于是乎会之，必大败之。”<br>3. 赵鞅誓师：“范氏、中行氏，反易天明，斩艾百姓，欲擅晋国而灭其君。寡君恃郑而保焉。今郑为不道，弃君助臣，二三子顺天明，从君命，经德义，除诟耻，在此行也。克敌者，上大夫受县，下大夫受郡，士田十万，庶人工商遂，人臣隶圉免。志父无罪，君实图之。若其有罪，绞缢以戮，桐棺三寸，不设属辟，素车朴马，无入于兆，下卿之罚也。” |
| 492 BC 春，齐卫围戚，向中山（鲜虞）求援。<br>夏，周卿士刘文公的大夫苌弘支持范氏（因刘文公与范氏世代联姻），赵鞅追究王室，周王室被迫处死苌弘 | 1. 三年春，齐、卫围戚，求援于中山...刘氏、范氏世为婚姻，苌弘事刘文公，故周与范氏。赵鞅以为讨。六月癸卯，周人杀苌弘。 —— 左传·哀公三年<br>2. 苌弘：字叔，苌宏，苌叔，资州人（四川资阳、内江资中），曾为孔子师，传说死后三年，其心化为红玉，血化为碧玉，有“苌弘化碧”、“碧血丹心”以喻忠诚正义。 |
| 491 BC 9月 赵鞅围邯郸，冬11月，邯郸城投降。荀寅逃往鲜虞，赵稷（邯郸午之子）逃往临地（河北邢台临城县）。12月，齐国大夫弦施前来接应。齐国大夫国夏伐晋，占领邢（河南温县北平皋村）、任（河北邢台任泽区）、栾（河北石家庄栾城区）、鄗hao（河北邢台柏乡县北）、逆畤zhì（河北保定顺平县东南）、阴人（山西临汾霍州市东南）、盂（山西太原阳曲县大盂镇）、壶口（山西长治市潞城区）等地。齐与鲜虞人会合，将荀寅护送入柏人（河北邢台隆尧县西）。 | 1. 九月，赵鞅围邯郸。冬十一月，邯郸降。荀寅奔鲜虞，赵稷奔临。十二月，弦施逆之，遂堕临。国夏伐晋，取邢、任、栾、鄗、逆畤、阴人、盂、壶口。会鲜虞，纳荀寅于柏人。—— 左传·哀公四年<br>2. 齐国夏伐晋占八邑之战没有更多史料。 |
| 490 BC 晋军包围并攻克柏人，荀寅、士吉射逃往齐国，范、中行氏之乱正式结束。<br>夏，赵鞅伐卫围中牟，中牟人叛，遂取之（春秋左翼39）。齐景公立幼子荼。<br>秋，景公卒。齐诸公子外逃，莱地人（山东烟台龙口附近）作《莱人歌》 | 1. 五年，春，晋围柏人，荀寅、士吉射奔齐。—— 左传·哀公五年<br>2. 《莱人歌》：“景公死乎不与埋，三军之事乎不与谋。师乎师乎，何党之乎？” —— 左传·哀公五年 |
 
## 勾践
    姒姓，本名鸠浅，越王允常之子，497BC至464BC在位

| 细节 | 备注 |
| --- | --- |
| 497 BC 允常去世，勾践继位。吴王阖闾趁机攻越。 | |
| 496 BC 槜李之战，勾践大败吴军于槜李（浙江嘉兴南），越大夫灵姑浮以戈斩落阖闾脚趾（左传定公十四年为以戈伤趾，史记为射伤），后阖闾因伤身亡，阖闾之子夫差继位吴王。 | 1. “越王句践使死士挑战，三行，至吴陈，呼而自刭。吴师观之，越因袭击吴师，吴师败于槜李，射伤吴王阖庐。” —— 史记41·越王勾践世家<br>2. 灵姑浮：官至大司马，于槜李之战回师途中病死。 |
| 494 BC 1. 夫椒之战：勾践听闻夫差日夜练兵，想先发制人，范蠡劝谏，不听，出兵，被吴精兵大败于夫椒（太湖椒山-焦山岛）<br>2. 会稽之困：勾践率5千残部被困于会稽山（绍兴会稽），范蠡谏：以厚礼进献吴王，他不同意的话，就亲自去周旋换取生机，勾践同意，派大夫文种赴吴。文种卑微地向吴王说：请让勾践为臣，勾践之妻为君之妾。伍子胥劝谏：“天以越赐吴，勿许。”吴王听谏拒绝。文种还，勾践欲杀妻焚宝带将士拼命，文种谏勾践吴太宰伯嚭pi贪，可以利诱，勾践派文种带美女宝物贿赂伯嚭，接受了，再带文种见吴王，文种请愿吴王赦免勾践，取宝物，如果不许，勾践将拼死。嚭劝：若赦之，国之利也。伍子胥谏：今不灭越，将为乱。吴王赦越，罢兵回师。<br>勾践叹：“吾终于此乎？”，文种：“商汤困夏台（河南禹州），周文王困羑you里（河南安阳汤阴县），晋重chong耳逃翟di（陕西中部渭水一带，陕西省铜川市），齐小白（齐桓公）逃莒ju（山东日照莒县），他们都称王称霸，由此，今日处境如何不是福分呢？”| 1. 蠡对曰：“持满者与天，定倾者与人，节事者以地。卑辞厚礼以遗之，不许，而身与之市。” ...种曰：“汤系夏台，文王囚羑里，晋重耳奔翟，齐小白奔莒，其卒王霸。由是观之，何遽不为福乎？” —— 史记41·越王勾践世家<br>2. 范蠡：字少伯，楚宛地三户邑人（河南淅川县三户村），出身贫贱，博学多才，文武双全。早年结识楚宛令文种，不满楚国政治，与文种投越，为勾践完成灭吴事业后功成身退，离开越国，三聚三散（十九年之中三致千金，再分散与贫交疏昆弟。—— 史记129·货殖列传）。因范蠡三迁皆有荣被后世尊为“文财神”、“商圣”。<br>3. 文种：曾任楚宛令（今河南南阳市区，古 宛县 令），后与范蠡投越，灭吴后被勾践赐剑（属镂/属卢）自刎（\~472BC），葬于会稽西山，得名“文种山（府山、卧龙山）”。 <br>4. 鸟尽弓藏，兔死狗烹：范蠡离越前给文种留书 “蜚鸟尽，良弓藏；狡兔死，走狗烹。越王为人长颈鸟喙，可与共患难，不可与共乐。子何不去？” —— 史记·越王勾践世家 |
